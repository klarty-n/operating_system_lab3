# Лабораторная работа № 3 — медианный фильтр

Программа применяет медианный фильтр к матрице в нескольких потоках. Для сборки в WSL:

```bash
cd ~/OS/operating_system_lab3/src
cmake -S . -B build
cmake --build build
```

Чтобы увидеть одновременно работающие потоки, сначала запустите **во втором терминале**:

```bash
watch -n 0.2 'ps -L -C lab3 -o pid,tid,stat,comm'
```

Затем **в первом терминале** запустите готовый большой пример:

```bash
cd ~/OS/operating_system_lab3/src/demo_threads
printf '11\n8\n' | ../build/lab3 -t 4
```

В выводе `ps` одинаковый `PID` означает один процесс, разные `TID` — отдельные потоки. Во время параллельного расчёта **5 строк без заголовка** означают главный поток и 4 рабочих. Результат записывается в `demo_threads/output.txt`
